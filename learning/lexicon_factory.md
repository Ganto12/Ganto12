# Lexicon factory: learning GPUs through worlds I already know, rendered as a 3D kernel world

Self-taught, I learn hard systems by mapping them onto worlds where I have 30,000+ hours: video games (Rainbow Six Siege) and the gym. The inside of a GPU becomes a gym franchise and a shooting range, locked into a canon only once each mapping survives a real kernel or number, and rendered as the 3D kernel world. It feeds the kernel and inference work and my mental models.

## Results

| Measured result |
|---|
| 58 locked canon lines |
| all 114 kernel tricks told in 2 frames (873 strings, 0 world leaks) |
| A kernel book, a 114-trick arsenal, a lexicon and step-by-step kernel and serving scenes |

## Method (in brief)

- How it fed the self-taught inference side: each mechanism (memory hierarchy, warps, prefill, decode, KV cache, collectives) was learned through a mapping and then tested against measured results.

## Limits

- Honest limit: the mapping is how I learn and teach, not a claim that it caused the results.
